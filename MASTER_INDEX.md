## 📞 Troubleshooting

### Docker Container Won't Start
- Check Docker daemon is running: `docker ps`
- Check port 5000 is available: `lsof -i :5000`
- Review logs: `docker logs web3-faucet-dapp`

### Tests Failing
- Ensure Node.js 18+ installed: `node --version`
- Install dependencies: `npm install`
- Run tests: `npm test`

### Frontend Issues
- Clear browser cache and reload
- Check MetaMask is connected to Sepolia
- Verify contract addresses in .env
- Check browser console for errors

### Wallet Connection Issues
- Ensure MetaMask extension installed
- Switch to Sepolia network in MetaMask
- Check if testnet has enough balance
- Try disconnecting and reconnecting wallet
